# Личная страница «Дизайнер и визуализатор»

Учебный проект по веб-технологиям. Лабораторная работа №3. Автор: Ялпута Семён

## О проекте

Одностраничный сайт-портфолио в пастельно-розовых и тёмно-серых тонах. Сделан как продолжение ЛР №2, но с добавлением адаптивной вёрстки на Flexbox и Grid по варианту 14 (стили и палитры).

## Файлы проекта

- `lab3.html` — главная страница
- `lab3.css` — стили
- `README.md` — описание (этот файл)
- `photos/photo_web.jpg` — моё фото
- `photos/bg.jpg` — фоновое изображение

## Что реализовано

- **Flexbox:** горизонтальное адаптивное меню навигации и карточки «Стили в дизайне» (4 шт.).
- **Grid:** галерея «Палитры недели» (сетка 2×2, на мобильных устройствах перестраивается в 1 колонку).
- **Адаптивность:** медиа-запросы для планшетов и телефонов, нет горизонтальной прокрутки.
- **Эффекты из ЛР №2:** плавный параллакс фона и его затемнение при заполнении формы.
- **CSS-переменные:** для основных цветов и для 16 цветов палитр (их hex-коды выводятся прямо в цветных блоках).
- **Семантическая вёрстка:** использованы теги `<nav>`, `<article>`, `<aside>`, `<header>`, `<footer>`.
- **Состояния элементов:** `:hover`, `:active`, `:focus`, `:visited` для ссылок и кнопок.
